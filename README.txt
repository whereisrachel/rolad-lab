ROLAD Lab (local edition) - runs entirely on this PC. No GitHub, no Claude, no internet needed.

1. Unzip this folder somewhere simple, e.g. C:\ROLAD-Lab
2. Double-click "Start ROLAD Lab.bat". Your browser opens the app (http://localhost:4747).
   Keep the black window open while tests run; closing it stops the lab (queued jobs resume next start).
3. Optional: double-click "Set up nightly runs.bat" once, so the explorer runs every night at 1:15 am.
   Your PC has to be on, signed in, and not asleep at that time.

Tabs: Run a test (compare lists or test cards), Explorer (finds missing pieces by itself),
Jobs (queue and progress), Results (plain verdicts), Card search (every legal card), Learned lines.
Everything is saved inside this folder (reports, data, lines).
